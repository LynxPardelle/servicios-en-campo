# Procedencia y reutilización

Fecha: 2026-11-19.

- Referencia conceptual: [LynxPardelle/BCAN](https://github.com/LynxPardelle/BCAN).
- Se tomó únicamente la idea comercial y el vocabulario general del dominio.
- No se copiaron archivos, historial Git, imágenes, marcas, contenido, credenciales, usuarios ni datos del repositorio de referencia.
- Angular se genera con herramientas oficiales y el código de la base de producto es nuevo.
- Esta separación no declara ni modifica los derechos sobre el proyecto de referencia.
- Incorporar en el futuro una pieza externa exige registrar su procedencia y condiciones antes de distribuirla.
